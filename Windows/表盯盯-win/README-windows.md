# 表盯盯 · Windows 版

装在一台 Windows 电脑上：**你选哪张表，它按间隔看一眼，有新增 / 修改 / 删除就发到你指定的飞书群，并在消息里 @ 你。**

## 文件

```
表盯盯/
├── 表盯盯.bat    ← 双击这个（缺 Python / Node / CLI 会提示或自动装）
└── app.py        ← 程序本体
```

## 第一次使用

双击 `表盯盯.bat`，它会依次：

1. 检查 Python（没有会打开下载页，安装时务必勾选 `Add python.exe to PATH`）；
2. 检查 Node.js/npm（没有会打开下载页）；
3. 缺 `lark-cli` 就自动 `npm install -g @larksuite/cli`；
4. 没登录就走 `config init` + `auth login`（浏览器里点同意）；
5. 后台启动配置页并打开浏览器 `http://127.0.0.1:8799`。

窗口出现"本窗口可以直接关掉"后，就可以关。

## 配置页里做什么

1. 粘贴飞书表格链接 → 点「① 读取子表」（会自动选中链接里那张子表并读表头）；
2. 选「哪一列里写着我的名字」（如 `修复人员`）；不选就是任何行改动都通知；
3. 填群机器人 Webhook 地址（群里「⋯」→ 设置 → 群机器人 → 添加自定义机器人，**签名校验关掉**）；
4. 点「保存」——会同时：
   - 自动建立基线（之后的变化才算改动）；
   - 自动注册 Windows 计划任务（每 N 分钟检查一次）；
5. 点「先发一条测试通知」确认群里收到（消息开头会 @ 你）。

## 后台任务

用 Windows 自带「任务计划程序」里的 `TableWatch` 任务，间隔就是配置页选的 1/2/5/10/30/60 分钟。
停止：配置页底部那行灰字右侧「停止后台检查」。

日志：`%USERPROFILE%\.tablewatch\run.log`
配置：`%USERPROFILE%\.tablewatch\config.json`

## 限制与说明

1. 电脑睡眠 / 关机时不检查；唤醒后下一次补上。
2. 「计划任务」按当前用户注册，不要把程序放进需要管理员权限的系统目录。
3. 本版按 macOS 版同一套逻辑移植，Windows 上的自动安装、计划任务注册、@ 提醒这几处需在你的机器上实际验一遍；出问题把窗口里的文字发我。
