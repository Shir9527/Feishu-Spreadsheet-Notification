# 表盯盯 · 本地版

装在你自己 Mac 上：**你选哪张表，它每 5 分钟看一眼，有新增 / 修改 / 删除就发到你的飞书群。**
不需要任何发消息授权，只要一个群机器人 webhook 地址。

## 文件只有 2 个

```
表盯盯/
├── 表盯盯.command   ← 双击这个，什么都没有它会自己装
└── app.py          ← 程序本体
```

`README-local.md` 是说明，看不看都行。

## 第一次使用

**双击 `表盯盯.command`**，剩下它自己处理。装好后配置页在后台运行，**终端窗口可以直接关掉**：

| 情况 | 它会做什么 |
|---|---|
| 没装 Node.js，但装了 Homebrew | 自动 `brew install node` |
| 没装 Node.js，也没 Homebrew | 打开 Node.js 下载页，装完再双击一次 |
| 装了 Node 但没飞书 CLI | 自动 `npm install -g @larksuite/cli`；权限不够会改用 `sudo`（要输开机密码） |
| 装了 CLI 但没登录 | 自动打开浏览器两次：配凭证 → 用飞书账号授权 |
| 都齐了 | 直接打开配置页 |

如果第一次双击被 macOS 拦（「无法验证开发者」）：右键 → 打开 → 再点「打开」，只需一次。

## 在配置页里做什么

1. 粘贴表格链接 → 点「① 读取子表」（会自动选中你链接里指的那张子表，并读出表头）；
2. 选「哪一列里写着我的名字」（可选）：
   - 选「修复人员」或「人员」这类写名字的列 → 只有这一列里写着你的那些行，改动才私信你；
   - **不选** → 这张表任何一行被改，都会通知你；
3. 点「保存」（第一次保存会自动建立基线，不用手动点）→「先发一条测试通知」确认群里收到 → 选检查间隔 →「启用自动检查」。

不用再选「认行键」「标题列」——程序自己找编号列认行，通知里直接把**整条记录**打出来。
再加一张表：点「+ 再加一张表」，重复 1–2 步，再「保存」。

## 通知长什么样

改动会这样发给你（整行都在，变了的字段标 ★）：

```
【Bug-QA&开发】11-20 16:50 · 1 处改动

▍第 42 行 改动（2 个字段变了）
  ID：41
  模块：道具促销弹窗
  bug描述：冰冻道具的道具促销弹窗上显示错误
  修改状态：待修复 → 已通过  ★
  修复人员：空 → 刘敏智  ★
```

## 通知方式：只发群机器人

1. 在目标飞书群里点「⋯」→ 设置 → 群机器人 → 添加自定义机器人；
2. **签名校验关掉**（开了的话，程序发不出去，会提示你去关）；
3. 复制 Webhook 地址（形如 `https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxx`），填到配置页「通知发到哪个群」。

想只让自己看到：建一个只有自己的群，把机器人加进去即可。

消息开头默认会 `<at>` 你本人（用你飞书账号的身份 @），手机上会收到提醒；不想被 @ 就把配置页那个勾去掉。

## 关窗口 / 重新打开

- 双击后弹出的终端窗口：可以关，后台检查照跑。
- 配置页关掉不影响检查；要再改配置，重新双击 `表盯盯.command`（不会重复启动，直接打开页面）。
- 配置页底部「关闭配置页（后台不停）」= 只关网页服务，后台照跑。
- 真要停掉定时检查，点「停止后台检查」。

## 文件位置

- 配置：`~/.tablewatch/config.json`
- 快照：`~/.tablewatch/state.json`
- 日志：`~/.tablewatch/run.log`
- 停止检查：配置页点「停止后台检查」

## 限制

1. 电脑睡眠或关机时不检查；唤醒后第一次会把期间变化合并成一条通知。
2. 只能监控**你有权限读**的表。
3. 认行键要稳定（首选编号列）。拿描述列当键，改一句描述会被判成"删一条 + 增一条"。
4. 检查间隔可选 1/2/5/10/30/60 分钟，改完会自动重新注册后台任务。
5. 飞书私信是纯文本，不渲染加粗。

## 常见问题

- **日志里反复出现「No such file or directory: 'lark-cli'」**：后台任务的 PATH 太干净。程序会把 CLI 绝对路径写进任务配置，重新双击一次 `表盯盯.command` 或点一次「保存」即可修好。
- **改了表到点没收到**：先在配置页点「查看状态 / 最近日志」，看「后台检查：已启用」和最新一行结果；再点「立即检查一次」验证链路。
- **机器人返回签名错误**：群里把自定义机器人的「签名校验」关掉。
